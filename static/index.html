Las reglas resaltan mensajes en amarillo (o el color que elijas) o los excluyen. Excluir puede ser «no guardar» (se descarta al recibir) u «ocultar» (se guarda pero no se muestra). Si varias reglas de resaltado coinciden, manda la primera de la lista.

Configurar el MikroTik

/system logging action
add name=logviewer target=remote remote=IP_DE_ESTE_SERVIDOR remote-port=4501

/system logging
add topics=firewall action=logviewer
# opcional: más topics (system, dhcp, wireguard, error, warning…)
add topics=system,error,warning action=logviewer

El receptor acepta el formato por defecto de RouterOS (topics mensaje) y también el formato syslog BSD con cabecera <PRI>Mmm dd hh:mm:ss host …. La hora que se guarda es la de recepción, porque el formato por defecto no incluye fecha.

Los logs de firewall salen si la regla tiene log=yes log-prefix=MI-PREFIJO.

Lenguaje de búsqueda

Los términos se combinan con Y. Un término suelto busca en el mensaje completo.

192.168.0.103texto en cualquier parte del mensaje
"TCP (SYN)"frase con espacios (entre comillas)
-udpnegar: no debe aparecer
src:10.0.0.0/8IP o red CIDR de origen (dst: para destino, ip: para cualquiera de las dos)
dport:853,443lista de valores (sport:, port: para cualquiera)
len:>100 len:<=64comparaciones numéricas
proto:tcp chain:forward prefix:FW-el texto del campo contiene el valor
in=bridge_lan state!=new= igualdad exacta, != distinto
/SYN.*ACK/ msg:/regex/expresión regular
if:wg_vpsinterfaz de entrada o de salida

Campos: src dst sport dport ip port mac proto flags in out if chain prefix topics level state mark nat len scope host msg. scope vale entrante / saliente / interno / externo según si las IP son públicas o privadas (no mira la interfaz).

Atajos en la tabla

Clic en una IP, puerto, interfaz, etc. → añade el filtro. Mayús + clic → lo excluye. Clic en la fila → detalle, con casillas para crear una regla a partir de los campos que marques.

Notas

El firewall del servidor debe permitir UDP 4501 desde el router. Si cambias el puerto a 4500, ten en cuenta que también lo usa IPsec NAT-T: si este equipo ejecuta IPsec, ese puerto estará ocupado.
